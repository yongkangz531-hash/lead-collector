# 风控与故障

## 参数落在哪

两套都是 `guard.py` 读写 `data/guard.json`，界面上的三档（保守/标准/很慢）改的就是这几个键：

| 键 | 含义 | 小红书默认 | 抖音默认 |
|---|---|---|---|
| `min_gap` / `max_gap` | 篇间随机间隔（秒） | 6 / 9 | 8 / 15 |
| `long_rest_every` | 几篇后长休 | 4 | 4 |
| `long_rest` | 长休区间（秒） | 25-45 | 35-100 |
| `max_notes_run` | 单轮上限 | 15 | 15 |
| `hourly_cap` | 每小时上限 | 30 | 30 |
| `cooldown_min` | 轮次冷却 | 10 | 10 |
| `quiet` | 安静时段 | 23-7 | 23-7 |
| `fail_pause_min` | 连败退避 | 30 | 30 |
| `fail_streak_limit` | 连败次数阈值 | 2 | 2 |

删掉 `guard.json` 等于把冷却和上限清零——**不要随手删**，那是保护账号的。

## 常见报错

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| `WinError 10061` | CDP 端口的 Chrome 没起 | 先拉起采集专用 Chrome（9333 / 9334） |
| `Session with given id not found` | 标签被换掉 | 重建标签，`Target.createTarget(url=...)` 直接带 URL |
| `Runtime.evaluate` 一直返回空 | 会话掉了 | 先 `1+1` 验活，失败重建（最多 3 次） |
| 打开后 /404 | 没走真实点击，或登录掉了 | 改派发真实鼠标事件；重新扫码 |
| 标题重复、评论 0 条 | 按索引点击错位 | 改为按 id 找卡片 |
| 跳过卡片仍重复采 | `score_rows()` 重建 dict 时丢了 id | 补上 `note_id` / `aweme_id` |
| 抖音评论节点存在但 `innerText` 为空 | 在浮层抽屉里解析 | 到整页 `/video/<id>` 上解析 |
| 抖音滚不动 | 改错元素；`comment-list` 是 `overflow:visible` | 滚 `.parent-route-container`；`mouseWheel` 坐标夹进视口 |
| 抖音越滚条目数不变 | 虚拟列表卸载旧节点 | 累计去重后再计数，别拿节点数当进度 |
| 界面停在「检查中…」 | `$("login")` 少了 `#`，异常被 catch 吞 | 用 CDP 直接读 DOM 排查 |
| 界面白屏 / `chrome-error://chromewebdata/` | Electron 走了系统代理 | `appendSwitch('no-proxy-server')` |
| Electron 里鼠标事件全失效 | 窗口没 `show()`，视图未布局 | 首查 `innerWidth`，为 0 就是没布局 |
| `IP存在风险 300012` | 走了本机代理 | Chrome 用 `--proxy-server="direct://"` |

## 写操作（关注 / 评论）的边界

采集是只读，安全边际大得多。要碰写操作（关注、发评论）时：

- 评论弹窗标题写「扫码验证」、内容其实是「请求太频繁，请一分钟后再试」——**这是限流，不是要扫码**
- 发送后回读编辑框：文字清空 = 成功，仍在 = 被拦
- 检测到验证/限流立刻停手，标签留前台，记冷却
- 节奏：评论 30-60 秒/条、单批 5 条、每天 15 条；关注 3-6 秒/人、单批 20
- 同一账号 10 分钟内别既采集又评论——混着做最快触发验证
- 抖音侧：写操作默认不做，判定比小红书更紧

## 数据落盘与清理

- `data/leads.jsonl` 按内容哈希去重，可以整份导出 CSV 给下游用
- `data/real_<关键词>.json` 是最近一轮原始评论，可以删
- `data/backup_*` 是历史备份，确认不需要再删
- 迁移机器时只搬代码，不搬 `data/`；换账号就删 `persist:*` 分区重新扫码
