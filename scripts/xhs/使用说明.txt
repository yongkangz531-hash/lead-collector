小红书采集台 · 使用说明（v2.0）
================================


这是小红书用的采集软件，和「抖音采集台」是两套完全独立的程序：

  端口不同（小红书 8788 / 抖音 8789）
  数据分开（各自的 服务\data）
  登录分开（各自的账号分区，互不覆盖）

两个可以同时开着用，不会互相干扰。




一、怎么启动

  双击「小红书采集台.exe」，等 10-20 秒窗口出来。
  左边是小红书，右边是控制台。

  切换界面有两种方式：
    · 控制台左上角「小红书采集台」右边三个小按钮：分屏 / 只看界面 / 只看浏览器
    · Ctrl+1 只看界面，Ctrl+2 只看浏览器，Ctrl+3 回到分屏
  「只看浏览器」时顶上留一条 40 像素的横条，横条上还有按钮，随时切回来。
  Ctrl+R 刷新控制台。

  第一次用要在这个窗口里登录小红书（只登一次，登录状态会记住）。
  以后打开就是登录好的，掉线了才需要重新扫码。




二、采集（先看这一节）

  控制台左上：关键词 / 二级词 / 篇数 → 点「开始采集」。
    · 关键词：主词，例如 装修
    · 二级词：可以填多个（用逗号或换行隔开），例如 报价,加盟,预算
      每个二级词会和主词拼起来再搜一遍（装修 报价、装修 加盟…），
      采回来的线索会标上它是哪个二级词出来的，后面可以单独筛。
      不填就只搜主词。
    · 篇数：这一轮打开几篇笔记（不是评论条数）。
      评论是滚多少得多少 —— 篇数给得多得到的评论也多，想多要线索就把篇数加大。

  采集过程中可以「暂停 / 继续 / 停止」，已采的都会保留。
  一轮跑完，右上角会显示 已采笔记 多少篇 · 线索 多少条。




三、线索表怎么看

  上面的表是笔记（文章），下面的表是人（线索）。

  人的那一行从左到右：
    昵称 / uid / IP / 时间 / 评论内容 / 意向 / 状态 / 关注 / 评论 / 私信
    意向  高（明确要买/要报价）/ 中（在做比较）/ 低（只是在聊）
    状态  新 / 已关注 / 已评论 / 已私信

  每一行右边三个按钮：关注、评论、私信，做过的会变成「已关注」「已评论」「已私信」，
  同一个人的同一个动作不会重复做。




四、筛选与排序

  线索表上面一排：
    · 采集时间 或 评论时间：选「评论时间」就按评论发出来的时间筛
    · 从 到：具体日期区间
    · 最近：1 / 3 / 7 / 30 天
    · 排序：最新在前 / 最早在前
    · 搜索框：搜昵称或评论内容
    · 全部二级词：只看某个二级词出来的线索
  设好点「应用筛选」，右边的「筛出 N 条」就是结果数。点「清筛选」恢复全部。




五、关注 / 评论（写操作，别催速度）

  关注：点行尾的「关注」，会真的点小红书的关注按钮。
  评论：点「评论」，会在那篇笔记下面发一条评论，内容从「评论词库」里随机挑。

  节奏和上限（软件自动控制，不要手动放宽）：
    · 评论：2-5 分钟一条，一天最多 15 条
    · 关注：每个之间有间隔，一批做太多会被平台拦
  如果页面弹了验证、滑块、或者提示操作频繁，软件会停下来，这时候要手动处理验证再继续。




六、私信

  先点「私信内容」，把要发的几句话写进去（一行一条），保存。
  然后两种发法：
    · 单个人：点行尾的「私信」
    · 一批人：勾选多个（左边方框），点「一键私信（勾选的人）」

  节奏和上限：
    · 每两条之间间隔 45-90 秒随机（「间隔」可调，建议别低于 45）
    · 每天最多 20 条（「每天最多」可调）
    · 同一个人只发一次，发过的不会再发
    · 连续失败 3 次会自动停下，避免一直撞风控

  重要限制（小红书自己的规则，软件绕不过去）：
    对方关注你或者回复你之前，你只能给他发 1 条消息。
    所以私信适合「发一次、把话说到位」，不要想着连续轰炸。
    对方主页关了私信的人，会提示「对方关闭了私信」，直接跳过。

  私信是真发出去的，收不回来。一次几十条之前，先用两三个人试水看回复率。




七、数据在哪

  线索、笔记、私信台账都在  服务\data  目录里：
    leads.jsonl        所有线索
    notes.jsonl        采过的笔记
    dm.json            私信台账（谁发过、什么时候、发的什么）
    followed.json      关注台账
    commented.json     评论台账

  换电脑就把整个「服务\data」拷过去。
  想清空重来，就把这些文件删掉（软件会自动重建）。




八、常见问题

  双击没反应 / 窗口是黑的
    多半是已经开着一个了。到任务管理器里把「小红书采集台」相关进程都结束，
    再双击一次。软件是单实例的，8788 端口被占就会退出。

  采不到评论
    1. 看左边窗口是不是登录着的，掉线就重新扫码
    2. 搜索页可能是验证页，手动过一次验证再采
    3. 关键词太窄，搜索结果本来就少

  私信点了没反应
    看控制台下面的状态：「今天已私信 x/20」如果到 20 了，第二天再发。
    如果是「平台限制」，就是对方没关注/没回复，只能发 1 条，已经发过了。

  显示"未绑定账号"
    窗口里登录一次小红书即可，账号信息会自动读出来。
